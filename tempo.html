Temporización de la UD Sistemas de control de versiones

Sesión 1 (1 hora)

Exposición magistral

El profesor hará una exposición magistral sobre qué son los sistemas de control de versiones y para qué se usan. Será breve y enfocada a motivar al alumnado.

Herramientas:

  • Apuntes de creación propia subidos a Google Classroom

Agrupamiento: individual

Duración: 10 minutos

Instalar Git y enlazar con VSC

Se instalarán todas las herramientas necesarias para el desarrollo de la UD y se enlazarán debidamente.

Herramientas:

  • Ordenador personal o del aula. Cualquier SO es válido: Linux, Windows o MacOS
  • Git
  • Cuenta gratuita en GitHub
  • Visual Studio Code

Agrupamiento: individual

Duración: 40 minutos

Sesión 2 (2 horas)

El alumnado creará un repositorio público en GitHub y aprenderá a realizar las acciones básicas: add, commit, push, pull, clone, fetch... desde VSC

El alumnado creará un repositorio público en GitHub y aprenderá a realizar las acciones básicas: add, commit, push, pull, clone, fetch... desde la terminal

Herramientas:

  • Ordenador personal o del aula. Cualquier SO es válido: Linux, Windows o MacOS
  • Git
  • Cuenta gratuita en GitHub
  • Visual Studio Code

Agrupamiento: individual

Duración: 50 minutos

Crear una página web personal y publicarla en GitHub (Parte I)

El alumnado creará una página web personal en GitHub y realizará el control de versiones del código mediante Git. En esta primera parte nos centraremos en crear el repositorio y dejarlo todo configurado.

Herramientas:

  • Ordenador personal o del aula. Cualquier SO es válido: Linux, Windows o MacOS
  • Git
  • Cuenta gratuita en GitHub
  • Visual Studio Code

Agrupamiento: individual

Duración: 1 hora

Sesión 3 (1 hora)

Crear una página web personal y publicarla en GitHub (Parte II)

El alumnado creará una página web personal en GitHub y realizará el control de versiones del código mediante Git. En esta segunda parte ya debería estar todo configurado y el alumno/a debería centrarse en crear el contenido de su web y gestionar las distintas versiones con Git.

Herramientas:

  • Ordenador personal o del aula. Cualquier SO es válido: Linux, Windows o MacOS
  • Git
  • Cuenta gratuita en GitHub
  • Visual Studio Code

Agrupamiento: individual

Duración: 1 hora

Sesión 4 (2 horas)

Crear un proyecto software colaborativo

Los alumnos/as se agruparán en parejas y/o trío y crearán un pequeño proyecto software en el que se intentará emeular el flujo de trabajo en un proyecto en el que múltiples persona programan a la vez, intentando que resulte lo más parecido a trabajar en una empresa.

Herramientas:

  • Ordenador personal o del aula. Cualquier SO es válido: Linux, Windows o MacOS
  • Git
  • Cuenta gratuita en GitHub
  • Visual Studio Code

Agrupamiento: parejas o tríos

Duración: 2 horas

Sesión 5 (1 hora)

Documentar las clases utilizadas en el proyecto software colaborativo

Partiendo de la página web iniciada en la sesión 2 y terminada en la 3 el alumno/a deberá agregar una sección de blog utilizando Jekyll.

Herramientas:

  • Ordenador personal o del aula. Cualquier SO es válido: Linux, Windows o MacOS
  • Git
  • Cuenta gratuita en GitHub
  • Visual Studio Code
  • Jekyll

Agrupamiento: individual

Duración: 1 hora

Sesión 6 (2 horas)

Documentar las clases utilizadas en el proyecto software colaborativo

A partir del proyecto software colaborativo de la sesión 4 los alumnos/as documentarán las clases implementadas

Herramientas:

  • Ordenador personal o del aula. Cualquier SO es válido: Linux, Windows o MacOS
  • Git
  • Cuenta gratuita en GitHub
  • Visual Studio Code

Agrupamiento: parejas o trios (manteniendo las de la sesión 4)

Duración: 1 hora y 30 mins

Prueba teorico-práctica tipo test y preguntas cortas

El alumnado realizará una pequeña prueba con 20 cuestiones. 10 tipo test y otras 10 de respuesta corta en las que deberán utilizar los comandos de Git aprendidos durante la UD.

Herramientas:

  • Ordenador personal o del aula. Cualquier SO es válido: Linux, Windows o MacOS
  • Formularios de Google Classroom

Agrupamiento: individual

Duración: 30 minutos
